## 📌 บทนำและความเป็นมา

พิธีฌาปนกิจในสังคมไทยมีความซับซ้อนในเชิงการบริหารจัดการ เนื่องจากมีขั้นตอนต่อเนื่องยาวนานและเกี่ยวข้องกับผู้มีส่วนได้ส่วนเสียหลายฝ่าย ทั้งเจ้าภาพ วัด และผู้ให้บริการปัจจุบันการดำเนินงานส่วนใหญ่ยังคงใช้โทรศัพท์ สมุดบันทึก และแอปพลิเคชันสนทนา ซึ่งเสี่ยงต่อการเกิดปัญหาการจองศาลาซ้ำซ้อน กำหนดการพึ่งพาความรู้เฉพาะบุคคล และการติดตามงานที่ยากลำบาก

ระบบนี้จึงถูกพัฒนาขึ้นเพื่อแก้ปัญหาดังกล่าว โดยเชื่อมโยงการทำงานทั้งระบบไว้บนฐานข้อมูลชุดเดียวกัน ลดภาระของเจ้าภาพ และเพิ่มความโปร่งใสในการจัดการ

## 🚀 ฟีเจอร์หลักของระบบ (Core Features)

1. **ระบบจองศาลาและสถานที่แบบ Real-time:** พร้อมกลไกตรวจสอบความขัดแย้งของช่วงเวลา (Conflict Detection) ป้องกันปัญหาการจองศาลาหรือเมรุซ้ำซ้อน
2. **ระบบจัดคิวพระสงฆ์และพิธีกร:** ผูกกับศาลาและคืนที่สวด พร้อมระบบแนะนำรายชื่อพระรูปอื่นกรณีเกิดคิวชนกัน
3. **ระบบแพ็กเกจบริการสำเร็จรูป:** รองรับ 3 ระดับ (Economy, Standard, Premium) พร้อมตัวเลือกย่อยและเครื่องคำนวณราคาประเมินแบบเรียลไทม์
4. **ระบบสร้างกำหนดการพิธีอัตโนมัติ:** คำนวณลำดับพิธีตั้งแต่รดน้ำศพ สวดพระอภิธรรม ฌาปนกิจ จนถึงการทำบุญ 7/50/100 วัน
5. **ระบบจัดการตามบทบาท (RBAC):** แยกสิทธิ์การใช้งานชัดเจน 5 กลุ่ม ได้แก่ Admin, Temple Staff, Operations Team, และ Host
